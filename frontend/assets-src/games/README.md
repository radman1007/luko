# نسخهٔ خوانای بازی‌ها

اینجا کدِ **مبهم‌نشده‌ی** بازی‌هاست — همان چیزی که باید ویرایش شود.
نسخه‌ای که در `public/games/` منتشر می‌شود، خروجیِ مبهم‌سازیِ همین فایل‌هاست.

## چرخهٔ کار

۱. بازی را همین‌جا ویرایش کنید (`grade-1/<درس>/NN-<نام>.html`)
۲. تله‌متری را در همان‌جا با `LUKO.answer / LUKO.hint / LUKO.finish` بزنید
۳. مبهم‌سازی و انتشار:

```bash
cd frontend/assets-src/games
npm install javascript-obfuscator          # فقط بارِ اول
cp -R grade-1/* ../../public/games/grade-1/
node obfuscate.cjs ../../public/games/grade-1/*/*.html
```

> مستقیم داخلِ `public/games/` ویرایش نکنید؛ با انتشارِ بعدی بازنویسی می‌شود.

## چرا مبهم‌سازی

هزینهٔ کپی‌برداری را بالا می‌برد، ولی **امنیتِ مطلق نیست**: هر کدی که در مرورگر
اجرا می‌شود، قابلِ خواندن است. برای محتوایی که واقعاً نباید لو برود، منطق باید
سمتِ سرور باشد.
